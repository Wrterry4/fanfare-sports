# Fonts

Download these six files here. They're referenced by name in `app.json`, so the
filenames must match exactly or `expo-font` will fail silently and everything
falls back to system fonts.

**Archivo** — https://fonts.google.com/specimen/Archivo
- Archivo-Bold.ttf
- Archivo-ExtraBold.ttf
- Archivo-Black.ttf

**Public Sans** — https://fonts.google.com/specimen/Public+Sans
- PublicSans-Regular.ttf
- PublicSans-SemiBold.ttf
- PublicSans-Bold.ttf

Archivo carries the scoreboard numerals and headings; Public Sans handles UI
text. If the scoreboard looks generic after a build, these didn't link.
